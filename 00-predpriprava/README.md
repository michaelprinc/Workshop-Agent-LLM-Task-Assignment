## Kontrola připravenosti

- [ ] Chat ve VS Code funguje a znám zvolený harness a model.
- [ ] Umím otevřít celou složku jednoho balíčku a prohlédnout diff.
- [ ] Mám vlastní větev nebo pracovní kopii čistého výchozího obsahu.
- [ ] Pro balíčky s kódem znám cestu ke svému Python interpreteru.
- [ ] Pro technický balíček je dostupný pytest ve stejném interpreteru.
- [ ] Znám dostupné nástroje a nastavení schvalování; nevkládám klíče do projektu.

Při potížích použijte [pomoc s prostředím](../docs/pomoc-s-prostredim.md). Před prvním úkolem začněte nový chat bez starších vyřešených pokusů.
