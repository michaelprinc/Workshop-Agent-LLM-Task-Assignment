# VS Code

Nainstalujte [Visual Studio Code](https://code.visualstudio.com/download), otevřete Chat a ověřte přihlášení a dostupný model. Na Windows lze chat otevřít Ctrl+Alt+I; názvy ovládacích prvků se mohou podle verze lišit.

Stáhněte tento účastnický repozitář a vytvořte vlastní větev. Potom otevřete **celou složku balíčku** přes File → Open Folder. Kořenem workspace má být například `balicek-technicke/`, nikoli jeho vnořený `projekt/` nebo pouze jeden soubor.

Dříve než workspace označíte za důvěryhodný, prohlédněte jeho konfiguraci. Načtení vlastních agentů a skills ověřte podle [průvodce](../../docs/agenti-a-skills.md). Pro terminál si vyberte správný Python interpreter a správnou pracovní složku; nemusí být totožná s kořenem workspace.
