# Střední — vlastní pokyny a role

**Předpoklady:** Balíček 1; připravený Python pro dodaný skript. **Čas cvičení:** 75–90 minut, navíc čtení a diskuse.

## Podklady a pracovní pomůcky

Projekt: [specifikace](projekt/pruzkum-spokojenosti/README.md). Projektové pokyny, redaktor a výpočetní skript. Vlastní analytik vzniká až během cvičení. Dodané pomůcky používejte podle zadání; vlastní výstupy si odvozujete a ověřujete sami.

## Začátek

1. Ve VS Code otevřete celou složku `balicek-2-stredni/`, aby `.github/` byla v kořenu workspace.
2. Projděte [kontrolu připravenosti](kontrolni-sestavy/pred-balickem.md) a [načtení konfigurací](../docs/agenti-a-skills.md).
3. Cvičení provádějte v pořadí. Před akcí připravte plán, po práci důkazy a vlastní záznam.

| Cvičení | Čas |
|---|---|
| [Projektové pokyny a rozsah souborů](cviceni/01-pokyny/uloha.md) | ~20 min |
| [Vlastní analytický agent](cviceni/02-vlastni-agent/uloha.md) | ~25 min |
| [Plán a předání mezi rolemi](cviceni/03-predani/uloha.md) | ~20 min |
| [Porovnání modelů](cviceni/04-porovnani-modelu/uloha.md) | ~20 min |

## Ověření a opakování

Používejte [obecnou teorii](teorie/README.md), [pomůcky](reference/README.md) a [závěrečný checklist](kontrolni-sestavy/po-balicku.md). Výsledky ukládejte do vlastní větve; nevkládejte je do výchozího main.

Pro opakovaný samostatný pokus začněte z čisté pracovní kopie a nového chatu. Šablonu konfigurací si můžete později upravit pro nový projekt; pokyny role nepředstavují technickou izolaci.
