# Pokročilý — postupy a koordinace

**Předpoklady:** Balíček 2; připravený Python. **Čas cvičení:** 90–120 minut, navíc čtení a diskuse.

## Podklady a pracovní pomůcky

Projekt: [specifikace](projekt/kvetinart-vytazky/README.md). Analytik, redaktor, skills validace-dat a tvorba-reportu, výpočetní skript. Vlastní skill vzniká během cvičení. Dodané pomůcky používejte podle zadání; vlastní výstupy si odvozujete a ověřujete sami.

## Začátek

1. Ve VS Code otevřete celou složku `balicek-3-pokrocily/`, aby `.github/` byla v kořenu workspace.
2. Projděte [kontrolu připravenosti](kontrolni-sestavy/pred-balickem.md) a [načtení konfigurací](../docs/agenti-a-skills.md).
3. Cvičení provádějte v pořadí. Před akcí připravte plán, po práci důkazy a vlastní záznam.

| [Vlastní skill pro opakovanou práci](cviceni/01-vlastni-skill/uloha.md) | ~20 min |
| [Použití dodaných postupů](cviceni/02-dodane-skills/uloha.md) | ~20 min |
| [Delegace nezávislých podúkolů](cviceni/03-delegace/uloha.md) | ~15 min |

## Ověření a opakování

Používejte [obecnou teorii](teorie/README.md), [pomůcky](reference/README.md) a [závěrečný checklist](kontrolni-sestavy/po-balicku.md). Výsledky ukládejte do vlastní větve; nevkládejte je do výchozího main.

Pro opakovaný samostatný pokus začněte z čisté pracovní kopie a nového chatu. Šablonu konfigurací si můžete později upravit pro nový projekt; pokyny role nepředstavují technickou izolaci.
