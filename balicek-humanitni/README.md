# Humanitní — od zdroje k reportu

**Předpoklady:** Balíčky 1–2; základní angličtina, bez programování. **Čas cvičení:** 90–120 minut, navíc čtení a diskuse.

## Podklady a pracovní pomůcky

Projekt: [specifikace](projekt/seminar-kava-v-evrope/README.md). Překladatel a skill shrnuti-zdroje. Vlastní postup porovnání vzniká během cvičení. Dodané pomůcky používejte podle zadání; vlastní výstupy si odvozujete a ověřujete sami.

## Začátek

1. Ve VS Code otevřete celou složku `balicek-humanitni/`, aby `.github/` byla v kořenu workspace.
2. Projděte [kontrolu připravenosti](kontrolni-sestavy/pred-balickem.md) a [načtení konfigurací](../docs/agenti-a-skills.md).
3. Cvičení provádějte v pořadí. Před akcí připravte plán, po práci důkazy a vlastní záznam.

| Cvičení | Čas |
|---|---|
| [První shrnutí podle vlastního zadání](cviceni/01-prvni-shrnuti/uloha.md) | ~15 min |
| [Opakované shrnutí dodaným skillem](cviceni/02-dodany-skill/uloha.md) | ~15 min |
| [Překlad se specializovanou rolí](cviceni/03-preklad/uloha.md) | ~20 min |
| [Vlastní postup a delegace](cviceni/04-vlastni-postup/uloha.md) | ~25 min |
| [Plán a závěrečný report](cviceni/05-finalni-report/uloha.md) | ~25 min |
| [Ověření ochrany zdrojů](cviceni/06-audit/uloha.md) | ~20 min |

## Ověření a opakování

Používejte [obecnou teorii](teorie/README.md), [pomůcky](reference/README.md) a [závěrečný checklist](kontrolni-sestavy/po-balicku.md). Výsledky ukládejte do vlastní větve; nevkládejte je do výchozího main.

Pro opakovaný samostatný pokus začněte z čisté pracovní kopie a nového chatu. Šablonu konfigurací si můžete později upravit pro nový projekt; pokyny role nepředstavují technickou izolaci.
