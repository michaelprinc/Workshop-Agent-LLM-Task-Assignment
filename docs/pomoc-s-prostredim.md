# Pomoc s prostředím

| Potíž | Postup |
|---|---|
| Agent nevidí podklady | Ověřte otevřenou složku a přiložte správný soubor přes výběr kontextu. |
| Vlastní role chybí | Ověřte `.github/agents/`, frontmatter a zvolený harness; zkontrolujte diagnostiku a nabídku agentů. |
| Skill chybí | Ověřte jeho adresář, `SKILL.md`, shodný `name` a dostupnost v přizpůsobení chatu. |
| Nástroj není dostupný | Ověřte jeho skutečný identifikátor a seznam nástrojů; alternativu dohodněte a zapište. |
| Python nebo pytest chybí | Použijte [návod k Pythonu](../00-predpriprava/navody/04-python.md); modul musí být ve stejném interpreteru. |
| Program nenajde vstupní soubor | Ověřte pracovní adresář terminálu a cestu uvedenou v zadání. |
| Model hlásí limit | Uložte průběh, zkraťte rozsah nebo pokračujte později; nenahrazujte ověření odhadem. |
| Delegace se neobjeví | Ověřte nástroj a podporu harnessu. Použijte oddělené chaty a označte to jako alternativu. |
| Změna proběhla bez dialogu | Ověřte pravidla automatického schvalování, prohlédněte diff a skutečná oprávnění. |

Průvodce řeší ovládání prostředí. Pokud nevíte, jak odvodit výsledek úlohy, vraťte se ke specifikaci a vlastnímu pozorování; požádejte o obecnou metodickou nápovědu.
