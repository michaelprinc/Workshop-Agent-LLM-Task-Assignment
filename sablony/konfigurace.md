# Prázdné šablony konfigurací

Doplňte vlastní obsah podle zadání. `example-role` a `example-procedure` jsou pouze zástupné názvy.

## Vlastní agent

```markdown
---
name: example-role
description: Doplňte účel role a kdy se má použít.
tools: ['read', 'search']
---
# Role
Doplňte pravidla a požadovaný výstup. Nástroje vyberte podle skutečné potřeby.
```

## Skill

```markdown
---
name: example-procedure
description: Doplňte, co postup dělá a kdy se použije.
---
# Postup
Doplňte kroky, vstupy, výstup a ověření.
```

## Pokyny pro soubory

```markdown
---
applyTo: 'projekt/**/dokumenty/**/*.md'
---
Doplňte pravidla formátu pro odpovídající soubory.
```

U každé změny ověřte podporu názvů a skutečné načtení. Textové pravidlo rozsahu zápisu není vynucené oprávnění systému.
